# 项目地图模板

用自己的项目替换下表中的虚构示例。工作区、提交和验收记录应注明核对日期，并在接手时重新确认。公开分享前检查本地路径和内部记录是否适合披露。

| 项目族 | 位置 | 用途 | 证据入口 |
|---|---|---|---|
| 示例数据工作台 | `projects/sample-workbench/` 和对应的导入 worktree | 研究数据导入、查询和展示 | 查分支、提交、导入报告与待办；部署状态待核对 |
| 示例消息助手 | `projects/sample-message-assistant/` | 消息队列与回复草稿 | 查项目指令、本地回归和人工验收记录 |
| 示例短片 | `projects/sample-film/` | 基于分镜和音轨制作预览 | 查剪辑工程、素材状态和最终导出件 |

同一项目的 worktree、候选版本和交付副本可按项目族归并。不同方向分别记录应该查阅的证据和位置。
